# 更新 Modus

仅当用户明确要求更新 Modus CLI 或当前项目的框架资产时读取本页。

## 更新流程

确认当前项目及安装包的管理工具，先执行 `modus update --dry-run --json` 查看具体变更，再按用户授权执行 `modus update --yes`。仅更新当前项目使用 `--project`，仅更新 CLI 使用 `--person`。依照宿主权限要求处理包管理工具写入。

## 所有权边界

只处理当前产品安装。保留 `modus/knowledge` 和人工修改；没有安装清单时不根据目录名接管文件，也不扫描或清理其他包、插件、旧目录或其他项目。

## 完成检查

检查 `modus --version`、`modus status --json` 与所选平台的六个技能。遇到权限或文件冲突时报告准确原因；不改用未经授权的删除或整目录覆盖。框架资产重投影使用 CLI init/update，不触发知识重新初始化。
